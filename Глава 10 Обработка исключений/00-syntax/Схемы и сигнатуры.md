# Схемы, фрагменты и сигнатуры из книги

Шилдт, «Java. Полное руководство», 12-е издание, печатные страницы 275–294 (PDF 276–295).
Это **авторские схемы и сигнатуры**, а не самостоятельные программы. Их нельзя передавать `javac` как законченный Java-файл. Комментарии сохранены; условные обозначения не заменены выдуманными классами.

Объяснения и команды: [заметка главы](<../Глава 10 Обработка исключений.md>).

## Общая структура try/catch/finally — страница 275

```java
try {
    // блок кода, где отслеживаются ошибки
}
catch (ТипИсключения1 объектИсключения) {
    // обработчик исключений для ТипИсключения1
}
catch (ТипИсключения2 объектИсключения) {
    // обработчик исключений для ТипИсключения2
}
// ...
finally {
    // блок кода, подлежащий выполнению после окончания блока try
}
```
