# Java по Шилдту

Учебный проект по книге Герберта Шилдта «Java. Полное руководство», 12-е издание. Примеры рассчитаны на Java SE 17.

## Сборка и запуск

Понадобятся JDK 17 и Maven. Убедитесь, что `mvn -version` показывает Java 17, затем выполните из корня проекта:

```powershell
mvn test
```

В IntelliJ IDEA откройте корень проекта как Maven-проект, выберите JDK 17 и запустите метод `main` класса `org.example.Schildt.Main`. Из терминала стартовый пример можно запустить после сборки:

```powershell
java -cp target/classes org.example.Schildt.Main
```

## Глава 9. Пакеты и интерфейсы

В папке «Глава 9 Пакеты и интерфейсы» находятся 44 Java-файла по печатным страницам 244-274 и две заметки для Obsidian:

- [Страницы 244-255: пакеты и доступ к классам](<Глава 9 Пакеты и интерфейсы/Глава 9 Пакеты и интерфейсы.md>).
- [Страницы 256-274: интерфейсы](<Глава 9 Пакеты и интерфейсы/Интерфейсы. Страницы 256-274.md>).

Примеры главы расположены отдельно от Maven-исходников. К конфликтующим именам классов и интерфейсов добавлены номера разделов: например, `IntStack08`, `IntStack12`, `IntStack15`, `MyIF11`, `MyIF14`. В разделе `06` варианты различаются суффиксами `06Basic` и `06Full`. Имена файлов, конструкторы и обращения к типам согласованы; алгоритмы, пакеты и уровни доступа сохранены. Главу можно компилировать целиком или по папкам. Команды запуска приведены в заметках. Дополнительные демонстрации, которых нет в листингах книги, отмечены в исходниках.

Для общей компиляции и запуска одного из примеров в PowerShell:

```powershell
$chapter = 'E:\GPT\Java\12-Schildt-\Глава 9 Пакеты и интерфейсы'
$sources = (Get-ChildItem -LiteralPath $chapter -Recurse -Filter *.java -File).FullName
$outDir = Join-Path $chapter 'out'
javac -encoding UTF-8 --release 17 -d $outDir @sources
if ($LASTEXITCODE -ne 0) { throw 'Ошибка компиляции' }
java -cp $outDir IFTest3
```

После переименования выполните в IntelliJ IDEA `Build → Rebuild Project`, чтобы обновить результаты компиляции.

## Глава 10. Обработка исключений

Разобраны печатные страницы 274–297 (PDF 275–298): глава 10 целиком и вводные страницы главы 11. В [заметке главы](<Глава 10 Обработка исключений/Глава 10 Обработка исключений.md>) находятся объяснения, ссылки на все примеры и команды запуска для PowerShell и IntelliJ IDEA.

В новой папке 16 Java-файлов: 14 обычных и 2 намеренно ошибочных в подкаталогах `expected-errors`. Обычная сборка должна исключать `expected-errors`; команды приведены в заметке. Схемы и отдельный фрагмент обработчика сохранены отдельно.
